🗺️ Echo Cave Mystery - AI Treasure Hunt Chatbot

Welcome to the Echo Cave Mystery, an immersive, AI-powered treasure hunt experience built with Botpress! 

This chatbot acts as "Cipher," a mysterious and ancient guide guarding an explorer's archive. Players must solve a sequence of 50 cryptic riddles to unlock the ultimate secret. 

✨ Key Features

🧩 50-Level Sequential Gameplay: Automatically fetches clues and validates answers using structured database integration.
🤖 Smart AI Hints: Leverages Generative AI to provide contextual, helpful hints without ever revealing the actual exact answer.
💬 Conversational Loop: Intelligently detects random or off-topic questions. Cipher stays completely in character, answers the question politely, and seamlessly loops the user back to the hunt (e.g., "Shall we return to the hunt?").
 ✅ Robust Validation:Custom JavaScript logic ensures precise answer validation by ignoring case sensitivity and extra spaces.
🏆 Dynamic Progression: Tracks user progress in real-time with a dedicated victory state upon completing the 50th and final clue.

🛠️ Tech Stack

Platform:Botpress Cloud
AI/LLM:Botpress LLMz / Generative AI
Logic Execution: Custom JavaScript (for guess validation & state management)
